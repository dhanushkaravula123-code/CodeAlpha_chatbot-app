# CodeAlpha Chatbot App

A FAQ chatbot built using Python and Streamlit.

## Features
- Chat-based UI
- Answers predefined FAQ questions
- Built with NLP
- Easy to deploy

## Technologies Used
- Python
- Streamlit
- NLTK
- Pandas
- Scikit-learn

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
